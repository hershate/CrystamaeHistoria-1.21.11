# CrystamaeHistoria 1.21.11-2 发布说明

**版本**：`1.21.11-2`（版本号语义：目标服务器版本-修订号）
**基线**：`1.21.11-1`（Paper 1.21.11 + Slimefun 5.0.0 迁移版）
**日期**：2026-08-15
**性质**：稳定性/安全性/正确性修订版——不改变玩法设计，无数据格式变更

本版本是 27 轮系统审计（[note/audit/](../audit/README.md)）的产出，共修复 **116+ 项缺陷**（全部源码逐类覆盖：法术 67 类、机械 5 台、gadgets 18 类、artistic/exhalted/materials 17 类、mobgoals 10 类、监听器 17 个、GUI 全部面板、PDC 全部类型、核心引擎/工具/命令/统计/常量类、4 类数据文件、组合操作序列、构建产物）。
威胁模型：改造客户端可注入任意物品 NBT/PDC；多用户高频率使用；长期高负载运行。

## 安全修复（重点）

| 类别 | 内容 |
|------|------|
| **反序列化攻击面** | `LocationDataType`（物品 PDC）原先无过滤执行 Java 反序列化，恶意字节流可实例化任意类——现以 `resolveClass` 类白名单过滤（合法 Location 对象图全在白名单内，**写入编码不变，历史数据兼容**）。`DoubleArrayDataType` 长度字段校验防负长度崩溃与超大长度 OOM（`9db17c0`） |
| **进度门槛绕过** | 液化池配方的玩家前置条件（尊贵物品满级进度门槛/时间/天气/群系）在 activePlayer 缺失或离线时被静默跳过——现失败关闭（`d081833`）。行为变化：此类配方现要求放置者在线 |
| **不可信物品输入** | 无 PDC/损坏 PDC 的充能法术板触发 `EnumMap.put(null)` NPE——现退还/销毁并告警（`9d9849e`/`1746e4c`） |
| **冷却绕过** | 物品冷却检查固定读主手，副手持冷却物品交互可绕过——改用 `event.getItem()`（`a5d1041`） |
| **经济原子性** | 施法原为先执行后扣费：施法回调异常时零成本无限重试——现先结算充能/冷却再施法+断路器（`9d9849e`） |

## 稳定性修复（NPE/崩溃链）

- **机械持久化数据防御**：全部机械的 BlockStorage 解析（材质/UUID/数字）与 PDC 反序列化（缺键/非法值/未知引用）失败关闭——损坏数据不再使机械永久失效或每 tick 报错（`d081833`/`4b99b32`/`80c6c1d`/`f26ae63`/`52e6e3c`）。
- **破坏流程闭合**：记录者面板 onBreak 的 NPE 会中断掉落（吞玩家输入物品）；现实祭坛的 NPE 发生在"芽已放置/故事已移除"后造成状态不一致——均已修复。
- **施法者离线路径**：弹射物/闪电/流星命中回调可晚于施法者下线，4 处链式 `getCasterAsPlayer()` NPE 穿透事件链——降级处理（`3be2e43`）。
- **视线空值**：看向天空施法（Break/贤者之石/露天矿井等）的 `getTargetBlockExact` null 链式 NPE——空目标跳过（`39506dc`/`9082276`）。
- **T5 记录者面板**：塞入已满故事物品即触发 `pushOutItem` NPE（blockMiddle 未初始化）——回退位置（`4b99b32`）。

## 功能缺陷修复（表述与实现不符）

- **弹射物拖尾从未生效**（上游遗留）：`summonMagicProjectile` 的 tick 消费者无任何驱动方，StarFall/Chaos/Hellscape 注册的周期效果从未执行——按召唤物同构驱动+断路器（`2693226`）。
- **法术集图鉴 7 处数值/标志错误**：治疗量误读伤害字段、缩放标志误读 `isDamageMultiplied`、范围判断误用击退值、弹射物击退误用普通字段——玩家所见与法术实际行为一致化（`b238d99`）。
- 睡袋刷床复制路径与离线残留（`9d06e03`）；寒风法术负面效果误调正面接口（`8d41424`）。
- 收纳袋：PDC 数组无校验致负库存污染、失败提示与实现不符（`f0be106`/`c787589`）。

## 内存与日志（长期运行）

- **无界增长修复**：`ExpCollector` 双映射、`TickingBlockNoGui.firstTickMap`、`Stand` 双映射在破坏时不清条目——放置/破坏循环持续泄漏（`80c6c1d`/`f26ae63`）。
- **实体泄漏**：`DisplayStandHolder.kill()` 先清存储再读展示架，每拆一台液化池残留一个盔甲架——修正时序（`7d7d148`）。
- **SpellMemory 生命周期**：strikeMap 无过期清理、离线条目永不删除、区块卸载异常中断全部清理、clearAll 遗漏——全量闭环（`c0d3b75`）。
- **日志风暴**：施法断路器异常改每法术仅首次记录；各断路器（tick/弹射物/临时效果）不再周期性重复抛异常（`22dafe8`）。
