# CrystamaeHistoria 0.8.0 发布说明

**版本**：`0.8.0`
**基线**：`0.7.0`（第六轮性能优化版——统计读取域收官）
**日期**：2026-08-17
**性质**：第七轮性能优化版——**落盘与持久化域**（perf 第 34-35 轮，
第 36 轮循环闭合），不改玩法设计，**无数据格式变更，旧存档完全兼容**

## 优化总览（服务器内真实基准量化，逐轮报告见 perf 索引）

| 轮次 | 域 | 成果 |
|------|----|------|
| 34 | 周期落盘脏判定跳过 | 统计纪元水位线（round-23 现成脏检测器）判定 player_stats 落盘 + config 运行期无写入方首周期后跳过——**稳态 0.69ms 全量序列化+写盘 → 2.44ns（~283,000x）**；关服 force 无条件冲刷；writeFlush/skipThenWrite/force 落盘语义断言全 true |
| 35 | 镀金器空载 tick 扫描减半 | 首扫空跳过次扫（结构性蕴含：0.75³ ⊂ 3³ 同谓词）+ 拾取点惰性缓存（round-4 模式补齐）：1.52x，**绝对量噪声级**（实测确认 Paper 空域实体扫描近免费——边界判定） |
| 36 | 收口 | 0.8.0 全量终验 + 空闲 soak + 收敛判定 |

## 不做项（本轮论证）

- `BlockStorage.addBlockInfo`：vendored Slimefun 5.0.0 已为纯内存写 +
  脏标记延迟持久化；`updateBlockInfo` 快速路径仅省 ~2 次并发映射操作
  （ns 级），插件调用点均为事件频率——不做。

## 设计模式沉淀（新增，与 0.7.0 模式清单并列）

28. **纪元复用为脏检测器**：写点全量递增的失效纪元（为缓存一致性
    引入）可零成本复用为持久化脏判定水位线——round-23 纪元在
    round-34 的第二次完全不同的用途。
29. **区域子集早退**：同谓词嵌套扫描中，外层区域为空时内层（子集）
    必空——结构性蕴含的跳过不需要运行时证明（round-35）。

## 过程治理记录

  ——收敛判定应持续接受复查修订，而非一次定论；

- `depend`/`softdepend` 与 0.7.0 一致。
