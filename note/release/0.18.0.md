# CrystamaeHistoria 0.18.0 发布说明

**版本**：`0.18.0`
**基线**：`0.17.0`（第十六轮性能优化版——每 tick 派发任务折叠域）
**日期**：2026-08-18
**性质**：第十七轮性能优化版——**驻留条目每 tick 重复解析域（r76-78）**。

## 本版变更

1. **晶簇驻留条目解析缓存**（`RealisationAltarCache.tryGrow`）：晶簇
   条目存活至被破坏为止（成熟 LARGE_AMETHYST_BUD 长期驻留），每株
   每 tick 的 `BlockPosition.getBlock()` 块解析 + 粒子中心
   `getLocation().add()` 两次分配 + 镀金株 `new DustOptions` 构造
   全部为位置恒定（构造即定）的重复解析——按条目缓存 Block 引用与
   粒子中心 Location（无失效协议：位置恒定；CraftBlock 为位置+世界
   包装，跨 chunk 卸载/重载安全），镀金 DustOptions 静态常量化
   （r59 族），`tryGrow` 补 isEmpty 早退（r1/r75 守卫模式一致性）。
2. **红线保持**：粒子调用的节拍、数量、类型完全不变（视觉语义）；
   `getType()` 每 tick 仍读（生长转换与防御移除判定不变）；缓存
   解析与新鲜构造经等价性断言**逐位一致 true**。
