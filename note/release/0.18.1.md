# CrystamaeHistoria 0.18.1 发布说明

**版本**：`0.18.1`
**基线**：`0.18.0`（第十七轮性能优化版——驻留条目重复解析域）
**日期**：2026-08-19
**性质**：稳定性/正确性修复版——审计第 34-66 轮（33 轮、42 提交）收口。

## 本版变更（7 项修复）

1. **临时融合工作台配方快照时序缺陷（功能完整性）** `d73a682`：配方表
   在类加载时点（Tools 注册段）快照，Gadgets/ArtisticItems 等后续注册段
   的全部 42 处增强合成配方缺失——工作台无法合成这些物品且原版回退无法
   产出 SF 物品。改为 `setupSlimefun()` 末尾显式收集。实机验证：8 玻璃
   +稀有融合锭成功合成天使方块×8。
2. **收纳袋 GUI 陈旧实例覆盖写回（数据丢失）** `317754d`：GUI 打开期间
   自动吸取路径更新 PDC 后，GUI 长持旧实例整体回写会静默丢失吸取的水晶。
   改为每次操作前从物品 PDC 重新同步（读-改-写）。双机器人实机验证。
3. **"有故事的"名称前缀叠加（上游遗留）** `38bcc64`：每个故事提交/祭坛
   提取重建都会再叠一层前缀。改为幂等剥离（自动自愈已污染存档物品）。
   .sfi 服务器端神谕实证单层前缀。
4. **空故事池假闪电 + 空发统计** `90d046f`：池空无写入时仍闪电、仍给
   独特故事解锁/编年史统计（玩家数据污染）。移入提交成功分支。
5. **Color 数据粒子无数据调用崩溃（迁移级缺陷）** `7750049`：Paper 1.21.x
   起 FLASH 等 Color 数据粒子在无数据重载下抛 IllegalArgumentException
   ——**现实祭坛每次成功提取故事与棱镜镀金器吸取路径均触发**（异常穿透
   tick）。`displayParticleEffect` 中央修复：补白色 Color 满足契约，视觉
   不变。祭坛/镀金器 E2E 全绿实证。
6. **test-wand 按 id 解析解耦** `eca4568`：按 id 循环解析消除对
   "id≡枚举名"无约束不变量的依赖（防御性，初判缺陷为误报已诚实更正）。
7. **BlockTier 注释对齐** `59e61b0`：分母 10000 与正确示例。
