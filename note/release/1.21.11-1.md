# CrystamaeHistoria 1.21.11-1 发布说明

**版本**：`1.21.11-1`（版本号语义：目标服务器版本-修订号）
**分支**：`feature/1.21.11-slimefun5`
**日期**：2026-08-15

## 目标与红线

将插件迁移至 **Paper 1.21.11 + Slimefun 5.0.0**（`REF/Slimefun4.1` 构建产物），并满足：

1. 服务器仅安装 Paper + Slimefun 5.0.0 即可正常运行（不依赖任何其他插件）；
2. 不改变插件的实际功能与玩法。

| Slimefun | SlimefunGuguProject 2024.3.1 → **com.github.slimefun:Slimefun:5.0.0** | 以 `REF/Slimefun4.1/target/SlimeFun4.1-5.0.0.jar` 安装到本地 Maven 仓库（provided） |

## API 适配（全部在 paper-api 1.21.11 / Slimefun 5.0.0 中逐项验证）

### Slimefun 5.0.0 破坏性变更

- **`SlimefunItemStack` 不再是 `ItemStack` 子类**（改为包装类）：
  - 需要 `ItemStack` 的上下文（配方数组、`RecipeItem` 输入、`CustomItemStack.create`、掉落/展示等）统一追加 `.item()`；
  - 需要 `SlimefunItemStack` 的上下文（物品注册、`RecipeType` 显示）按编译错误精确回退；
  - `asQuantity(int)` 现返回 `ItemStack`，相关调用保持不变。
- **`CustomItemStack` 构造器私有化**：`new CustomItemStack(...)` → `CustomItemStack.create(...)`，相关字段/返回类型由 `CustomItemStack` 改为 `ItemStack`。
- **`RecipeType` 构造器**：`CrystaRecipeTypes` 使用 `(NamespacedKey, SlimefunItemStack)` 重载。

### Paper 1.19 → 1.21.11 枚举改名

- EntityType：`FIREWORK→FIREWORK_ROCKET`、`MUSHROOM_COW→MOOSHROOM`、`SNOWMAN→SNOW_GOLEM`
- PotionEffectType：`CONFUSION→NAUSEA`、`DAMAGE_RESISTANCE→RESISTANCE`、`FAST_DIGGING→HASTE`、`HARM→INSTANT_DAMAGE`、`INCREASE_DAMAGE→STRENGTH`、`JUMP→JUMP_BOOST`、`SLOW→SLOWNESS`、`SLOW_DIGGING→MINING_FATIGUE`
- Particle：`REDSTONE→DUST`、`SMOKE_NORMAL→SMOKE`、`CRIT_MAGIC→ENCHANTED_HIT`、`ENCHANTMENT_TABLE→ENCHANT`、`EXPLOSION_NORMAL→POOF`、`FIREWORKS_SPARK→FIREWORK`、`SLIME→ITEM_SLIME`、`SNOW_SHOVEL→SNOWFLAKE`、`SPELL→EFFECT`、`SPELL_WITCH→WITCH`、`VILLAGER_ANGRY→ANGRY_VILLAGER`、`VILLAGER_HAPPY→HAPPY_VILLAGER`、`WATER_SPLASH→SPLASH`
- Material：`GRASS→SHORT_GRASS`（Java 代码与 blocks.yml/block_colors.yml 数据）
- 其他：`Enchantment.LUCK→LUCK_OF_THE_SEA`、`ItemFlag.HIDE_POTION_EFFECTS→HIDE_ADDITIONAL_TOOLTIP`、`Attribute.GENERIC_MAX_HEALTH→MAX_HEALTH`、`Material.CHAIN→IRON_CHAIN`、`SCUTE→TURTLE_SCUTE`（数据文件）
- `Tag.TALL_FLOWERS` 被移除：`HarmonysSonata` 以本地 `EnumSet`（向日葵/丁香/玫瑰丛/牡丹/瓶子花）等价替代
- `getNearbyEntitiesByType` 泛型推断变化：`AbstractGoal.getTargetClass()` 收紧为 `Class<? extends LivingEntity>`

### 其他

- `ConfigManager.saveAll()`：`FileConfiguration.save()` 需显式传入 `config.yml` 文件。
- 遮蔽物（BlockVeil）：货物/能量遮蔽物改为无条件注册（原本仅在未安装 HeadLimiter 时注册，目标环境恒等价）；作用于 Networks 插件方块的网络遮蔽物随依赖一并移除。
- 删除 `NetheoPlants.java`（45 颗下界种子，依赖 Netheopoiesis）。

1. 物品/材料/药水效果名称展示由 GuizhanLib 中文回退为 Title Case 英文（玩法不受影响）。
2. 第三方插件集成全部移除：在未安装这些插件的服务器（即目标环境）上行为与原版完全一致。
3. 玩家统计与法术冷却等持久化编码未变，旧存档数据可继续读取。
