**版本**：`0.12.0`

不改玩法设计，**无数据格式变更，旧存档完全兼容**

## 优化说明

- **粒子批量化（r57）**：`displayParticleEffect`（施法/装置粒子效果
  的最常用入口，数十处调用点）N 次单发调用归一为 `count+offset`
  单次调用，散布由客户端原生生成；方法签名不变（零 API 面变化）。
  视觉形态同为逐轴均匀云（原 `+0.1` 非对称上界为上游遗留）。生产
  环境每跟踪玩家每调用另有 N 个粒子包→1 个包的网络收益。
- **NamespacedKey 常量化（r59）**：Prism/AntiPrism 对抗标记与回忆
  水晶格路标位置共 6 处回调内构造转 `Keys.PDC_*` 静态常量。

## 兼容性

- 无数据格式变更（PDC 键名逐一保持：PRISM/ANTIPRISM/location）；
  对外插件 API 不变；`depend`/`softdepend` 与 0.11.0 一致。
