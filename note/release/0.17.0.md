# CrystamaeHistoria 0.17.0 发布说明

**版本**：`0.17.0`
**基线**：`0.16.0`（第十五轮性能优化版——方块写入标志域）
**日期**：2026-08-18
**性质**：第十六轮性能优化版——**每 tick 派发任务折叠域（r73-75）**。

## 本版变更

1. **头部旋转动画折叠进 process() 每 tick 驱动**
   （`ChroniclerPanelCache`）：`FloatingHeadAnimation` 是全库唯一
   随机械工作状态长期存活的 period=1 调度任务（每工作面板一个，自
   setWorking 起每 tick 派发直至 setNotWorking/关服）——而面板
   `process()` 本身已由 Slimefun BlockTicker 每 tick 驱动，两路同
   节拍。折叠后：动画路径 54.35 → 21.7 ns/tick/面板（~2.5x，绝对量
   噪声级）；**消除全库唯一长期每 tick 任务类**（此后所有调度任务均
   为施法级/秒级/生命周期级）；**卸载区块空转消除**（面板在已卸载
   区块保持 working 时，旧任务对无人可见的盔甲架持续每 tick setHeadPose
   直至关服）；任务对象/生命周期管理简化为单字段。
   `FloatingHeadAnimation` 类删除（全库唯一使用者）。
2. 语义等价：任务驱动与直接驱动的头姿增量经 10 步实测**双精度逐位
   一致**；节拍等价由两边同为每 Minecraft tick 驱动保证；展示架引用
   的陈旧语义与原任务持引用完全一致（被外部移除时同样静默失效，
   下次 setWorking 重建）。
