# CrystamaeHistoria 0.16.0 发布说明

**版本**：`0.16.0`
**基线**：`0.15.0`（第十四轮性能优化版——判定收敛版）
**日期**：2026-08-18
**性质**：第十五轮性能优化版——**方块写入标志域（r70-72）**。

## 本版变更

1. **面板光源呼吸动画免 physics**（`ChroniclerPanelCache.animateLight`）：
   `setBlockData(data)` 单参形态在 Paper 中默认 `physics=true`（CraftBlock
   字节码实证 → NMS flag 3：邻居通知 + 观察者可见）。全库唯一每 tick
   方块写入热站点（每工作面板每 tick）改 `setBlockData(data, false)`
   （flag 530：客户端状态更新保留）：全序列 1954.43 → ~285ns，
   **~6.9x**（20 面板同开每 tick 省 ~33µs）。保留每 tick 新读
   `getBlockData`——发光勺外部调节面板光源的语义完全保留。
2. **HarmonysSonata 花朵写入族一致性**（4 处补 `physics=false`）：
   与同函数高花路径既有惯例对齐（bisected 半位写回 ×2 / DANDELION /
   单体花；GRASS_BLOCK 地面转换维持 physics）。
3. **语义红线口径沉淀**（判定保留项）：作物催熟（GreenHouseGlass）、
   晶簇生长（RealisationAltarCache）、临时方块 AIR 移除、用户工具
   写入（LuminescenceScoop）保留 physics——玩家可构建依赖的玩法语义
   （观察者农场/附着物清理）；插件内部装饰效果的写入不带 physics
   （上游 HarmonysSonata/Cascada 既有惯例）。
