# CrystamaeHistoria 0.13.0 发布说明

**版本**：`0.13.0`
**基线**：`0.12.0`（第十一轮性能优化版——粒子批量化与常量化域）
**日期**：2026-08-17
**性质**：第十二轮性能优化版——**生成预配置与复用域（r62-65）**，
不改玩法设计，**无数据格式变更，旧存档完全兼容**

## 优化总览（服务器内真实基准量化，逐轮报告见 perf 索引）

| 轮次 | 域 | 成果 |
|------|----|------|
| 62 | 实体生成预配置 consumer 化（三路径） | 弹射物 **1.93x**（2584→1340ns）/ 展示物 **1.54x** + 每跟踪玩家元数据包 N→1 收益 |
| 63 | FallingBlock 的 BlockData 静态复用 | **16.56x**（65.1→3.9ns，高等级陨石每施法省 ~0.13ms） |
| 64/65 | 判定轮 ×2（快照/区块/特效 + 射线/眼部形态） | 零发现——**第十二轮循环收敛** |

## 优化说明

- **生成预配置（r62）**：弹射物（19+ 法术共享）/ 召唤物（PDC+蛋名，
  AI 目标保守留生成后）/ 展示物（五类机械展示架，七项配置）三路径
  改 `spawn`/`dropItem` 的 **consumer 重载**——配置在实体加入世界前
  应用，生成包即携带终态（原形态生成后逐 setter 各发一次元数据
  同步包）。无 Class 映射类型保留原路径回退。
- **BlockData 复用（r63）**：`summonMagicFallingBlock` 新增 BlockData
  重载（内部 API，Material 版保留）；PlutosDecent 四黑石材质静态
  缓存（不可变配置跨生成复用，服务器内 3 连生成断言正确）。

## 兼容性

- 无数据格式变更；生成物终态逐项等价（字段 + PDC 断言 true）；
  对外插件 API 不变（新增重载为内部工具类新方法，旧签名全部
  保留）；`depend`/`softdepend` 与 0.12.0 一致。
