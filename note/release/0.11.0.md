# CrystamaeHistoria 0.11.0 发布说明

**版本**：`0.11.0`
**基线**：`0.10.0`（第九轮性能优化版——复查长尾域收官）
**日期**：2026-08-17
**性质**：第十轮性能优化版——**事件级门控域（r53-56）**，不改玩法
设计，**无数据格式变更，旧存档完全兼容**

## 优化总览（服务器内真实基准量化，逐轮报告见 perf 索引）

| 轮次 | 域 | 成果 |
|------|----|------|
| 53 | 事件级 getByItem 材质门控（8 处高频处理器） | miss **2.91-3.00x**（18-21→6-7ns）/ 36 槽扫描 **2.81x**（547→195ns） |
| 54 | 判定轮（BlockStorage/菜单/字符串三角度） | 零发现 |
| 55 | 实体扫描 ByType 切片化 | 阴性结果回退（living 回退 -36.8%——Paper 1.17+ 实体扁平化） |
| 56 | 判定轮（循环重复调用角度） | 零发现——**第十轮循环收敛** |

## 设计模式沉淀（新增，与 0.10.0 模式清单并列）

35. **getByItem 双路径成本**（r53）：miss 路径 ~19ns 廉价短路，hit
    路径 1.3µs（meta+PDC）——事件级门控收益预期按路径修正；门控
    同时对 Slimefun 未来成本变化免疫。
36. **平台版本敏感性**（r55）：教科书式优化假设（类型切片索引）
    随上游架构变迁失效——Paper 1.17+ 实体存储扁平化，
    ClassInheritanceMultiMap 切片不复存在；任何跨版本结论须按当前
    服务端实测复核。

## 兼容性

- r53 门控全部为纯前置材质短路（材质不等即返回），判定语义零变化
  （全族等价性断言 true：3 法杖 + 水晶采样 + 收纳袋 + 盐/透镜 +
  原版样本含门材质本体）；
- 无数据格式变更；对外插件 API 不变；`depend`/`softdepend` 与
  0.10.0 一致。

## 循环收敛判定（round-56）

第十轮循环总账：实质清扫 1 轮（53）、阴性边界 1 轮（55）、判定
轮 2 轮（54/56 零发现，角度互异）——r44 准则达成，**第十轮性能
优化循环于 round-56 收敛闭合，版本收口 0.11.0**。JIT 边界证据链
累计五证；剩余性能面为 API 边界、事件级边际与平台架构边界三类。
重启触发条件不变：Paper/Slimefun 演进、玩法变更、集成环境实测
画像。
