# CrystamaeHistoria 0.5.0 发布说明

**版本**：`0.5.0`
**基线**：`0.4.0`（第三轮性能优化版）
**日期**：2026-08-16
**性质**：第四轮性能优化版——图鉴展示/统计读取两域（perf 第 21-23 轮，
第 24 轮为阴性结果回退，第 25 轮循环闭合），不改玩法设计，
**无数据格式变更，旧存档完全兼容**

## 设计模式沉淀（新增，与 0.4.0 模式清单并列）

16. **启动期排序快照**：运行期不可变集合的视图排序（翻页/遍历用）
    在启动/构造期一次完成，消费方直接 subList——同时消除对共享
    缓存数组的原地重排污染。
17. **纯函数展示物记忆化 + clone 返回**：构建输入全为常量的展示物品
    （图标/详情堆）按 key 记忆化，`clone()` 返回保持每格独立实例语义。
18. **页级子节单次解析**：对同一父节点下的多次 YAML 路径读取，先解析
    子节再做相对读取（单层行走替代全路径逐层行走）。
19. **纪元失效缓存**：写点全量封闭时（grep 核验 + 文件运行期不重载），
    以写方法递增全局纪元作为缓存失效协议，读方字段级纪元校验。
20. **（阴性）"新 API 更快"须实测**：adventure 组件 lore 应用在
    Paper 1.21.11 上反直觉地慢于 legacy 字符串路径；触及 Paper 内部
    序列化边界必须以真实 ItemMeta 实测为准（round-24 全程记录）。

## 附带修正与沉淀

- **基准除数缺陷更正**：round-22 standalone 计数变体未按 `size` 循环被
  Harness 误除，countStories274 真实比率 1.89x（原报告 6.3x 失真）——
  报告已更正，`benchmark/README.md` 立形态红线；
- **规模勘误**：`blockDefinitionMap` 实为 ~998 个方块定义（此前文档引用
  的 274 为 blocks.yml 顶层节数）；
- **红线口径澄清（用户，2026-08-16）**：兼容 = 用户体验一致 + 对外
  插件 API 不变；内部实现/内部调用可自由重构，不必逐方法等价——
  写入 perf README 与 note README，适用于后续所有轮次。

## 兼容性

- 磁盘存储/PDC 编码/BlockStorage 键**零变更**——旧存档、法杖、法术板、
  机械数据全部可读；
- `getEnabledSpells()` 数组顺序从"枚举序（首开图鉴后变 id 序）"变为
  "恒 id 序"——全部调用方顺序无关，图鉴分页与旧终态一致；
- `hasUnlocked*` 判定语义即时性不变（未缓存）；统计计数写入后立即可见
  新值（纪元失效保证，断言实证）；
- `depend`/`softdepend` 与 0.4.0 一致。
