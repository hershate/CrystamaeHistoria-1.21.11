## 设计模式沉淀（新增，与 0.2.0 模式清单并列）

6. **UUID 反查索引**：世界级事件（任意实体命中/死亡）的 wrapper 反查以
   `Map<UUID, wrapper>` 索引取代 stream 线性扫描；索引与主表在注册 API 同步维护。
7. **类型门控**：PDC 消费型监听器前置 EnumSet/材质/`hasItemMeta` 门槛——
   非候选实体/物品零成本跳过；召唤物类型白名单运行期自动登记。
8. **会话内注册表**：极短过期（≤ 重启耗时）的实体标记以内存 Map 取代实体 PDC，
   消除每次相关事件的 NBT 读与残留键。
9. **脏标记落盘**：机械 BlockStorage 写仅在内容实际变更的 tick 末尾执行一次。
10. **冷路径画像**：onEnable 分段计时是启动优化的先决设施。

## 基础设施（benchmark/）

- 基准组链式调度（组间让出 tick，watchdog 安全）；run-server-bench.sh
  会话脚本（残留服务端清理 + 状态汇报）；等价性运行时断言模式
  （门控优化在基准内对新旧路径做行为一致性断言）。

## 兼容性

- 磁盘存储/PDC 编码/BlockStorage 键**零变更**——旧存档、法杖、法术板、机械数据全部可读；
- 行为等价论证逐轮落盘（round-10 索引同步边界/round-11 终态一致/round-12 落盘
  终态逐字节等价/round-13 门控等价 + 运行时断言）；唯一惰性残留：旧实体 NBT 中
  的 `invul` 键无人读取（无害）。
- `depend`/`softdepend` 与 0.2.0 一致。
