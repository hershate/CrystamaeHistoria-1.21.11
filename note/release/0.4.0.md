## 设计模式沉淀（新增，与 0.3.0 模式清单并列）

11. **单次元数据往返提交**：读-改-写序列（多方法各自 getItemMeta/setItemMeta）
    归并为单次克隆 + 单次应用；终态逐字段等价，异常原子性优于旧中间态。
12. **不可变展示行记忆化**：输出仅依赖构造后不可变字段的展示构建
    （组件→legacy 转换）以实例级懒缓存消除，列表以不可变副本共享。
13. **构造互异去重的消除**：枚举三重循环坐标组合构造上互异时，
    List.contains 去重与中间对象分配均为 O(n²)/O(n) 无效工作。
14. **在线判定单查询**：getOfflinePlayer+isOnline+getPlayer 三步 ⇔ 单次
    getPlayer（同 UUID 在线语义等价）。
15. **单次克隆可复用坐标**：循环内每粒子 clone().add → 基准坐标 set
    （消费方同步读取无逃逸；实测收益边际，见 round-19 域判定）。

## 附带修复与遗留发现

- **稳定性（已修）**：祭坛提取遇故事列表缺失（损坏数据）按空处理失败关闭
  （原 NPE 穿透 tick）。
- **文档（已修）**：TunnelBore/Runnable 过时的 "Removed due to issues" 注释
  更正为实际语义。
- **上游遗留（未修，留待审计轮）**：`rebuildStoriedStack` 每次在既有显示名上
  叠加"有故事的"前缀（旧/新行为一致；游戏内单物品 ≤11 层；修复涉及可见
  行为变更）。
- **回退记录**：Spell.getName 懒缓存试行后回退（69 法术全部覆写 getName，
  基类实现运行期不可达）。

## 兼容性

- 磁盘存储/PDC 编码/BlockStorage 键**零变更**——旧存档、法杖、法术板、机械
  数据全部可读；
- 每轮行为等价论证 + 运行时断言（round-15 四组终态断言 / round-16 采样断言 /
  round-17 四组 / round-18 坐标序列 / round-19 位置序列）全部通过；
- `depend`/`softdepend` 与 0.3.0 一致。
