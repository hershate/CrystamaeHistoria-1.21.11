## 设计模式沉淀（新增，与 0.9.0 模式清单并列）

32. **探针角度轮换准则**：r48（残余流/克隆/反模式）零发现被 r49
    （List.contains 角度）实质发现修订——单一角度的零发现不可作为
    地板证据，判定轮必须轮换探针角度（r49 方法论沉淀）。
33. **EA 逃逸形态边界（四证）**：r19/r38/r46/r47 四次实证——不逃逸
    的短命对象分配在 C2 下近免费；清扫目标应锁定逃逸形态
    （流包装/二次传递/跨调用保留）。
34. **阴性结果回退纪律**：数学精确等价（r50 平方比较）但无实测收益
    的变更按 r24 先例回退，基准证据保留为边界文档。

## 过程治理记录

- r49 会话 CH_ERRORS=1 为计数器误报（watchdog 线程转储堆栈帧含插件
  类名），逐行核验非插件缺陷——计数器口径缺陷已识别；
- r47 首跑 pose=false 为基准断言设计缺陷（起点未归零），归零复测通过，
  如实归档（与 r35 dropItem 散落同类：断言失败先查断言设计）；
- r42-52 全程真实插件异常 0（watchdog 转储均为基准重负载旧变体批次
  固有现象，r49 报告定位归档）。

## 兼容性

- 无数据格式变更；全部优化为内部实现形态（静态缓存/直接迭代/死逻辑
  移除），物品 PDC/BlockStorage/统计 YAML 读写语义不变；
- 对外插件 API 不变；`depend`/`softdepend` 与 0.9.0 一致；
- `FloatingHeadAnimation.Y_DEVIANCY`（内部常量，无外部消费者）随死
  分支移除；`SPEED` 保留。

## 循环收敛判定（round-52）

（50）、卫生 1 轮（47）、判定轮 5 轮（42/43/48/51/52）。地板判定

（复查长尾域）于 round-52 收敛闭合，版本收口 0.10.0。**重启触发
条件不变：Paper/Slimefun 演进、玩法变更、集成环境实测画像。
