## 设计模式沉淀（新增机械/法术时的性能红线）

1. **实例判定备忘录**：GUI 槽物品判定结果在"实例未变且未被本机械修改"时恒定——
   引用比较即完备失效检测，修改点显式置空（面板/祭坛已内置）。
2. **懒计算 + 冻结**：构造期不做昂贵计算（raycast/JSON），前置校验通过后、
   执行前统一冻结，跨 tick 回调读施法瞬间值。
3. **单次元数据往返**：一次交互/一个 tick 内的多个 PDC 判定共用一次
   `getItemMeta`；写回时 PDC 与 lore 共用一次 `setItemMeta`。
4. **材质预检**：冷却/调光勺等 PDC/SF 检查前先比材质（写入方材质集合固定）。
5. **启动期索引**：运行期不可变的数据（故事表）建索引，运行期 O(1) 查表。

## 兼容性

- 磁盘存储/PDC 编码/BlockStorage 键**零变更**——旧存档、法杖、法术板、机械数据全部可读；
- 公共 API：`StoryUtils`/`InstanceStave` 旧签名保留（新增重载）；`addStory` 签名变更
  仅涉内部唯一调用方；
- `depend`/`softdepend` 与 0.1.0 一致。
