# 性能优化第 57 轮：随机云粒子批量化（第十一轮循环开启）

日期：2026-08-17
域：**粒子 API 调用形态**——r19 只清了粒子循环的 Location 分配，
本轮探针发现 `spawnParticle` 的 **count+offset 重载**可让随机散布
云整循环归一为单次调用：偏移由客户端原生生成（逐轴均匀盒偏移），
服务端零循环、零随机数、**每调用 N 个粒子包 → 1 个包**。

## 实现（本轮提交 e9d15fd）

`ParticleUtils.displayParticleEffect` 两个随机云变体（普通 /
DustOptions）：

- 原：N 次单发 `spawnParticle(particle, point, 1)`——每粒子 3 次
  `nextDouble` + 3 次坐标 set + 1 次调用（1 包/次）；
- 新：单次 `spawnParticle(particle, location, N, r, r, r[, dust])`
  ——客户端按盒偏移生成云（1 包/调用）。

方法签名不变（纯内部形态，零 API 面变化）。其余 12 处
`spawnParticle` 调用点复核均为刻意几何位置（光源高亮/星轨/振动/
画线），不可批量。散布形态：同为逐轴均匀云；原 `+0.1` 非对称上界
为上游遗留，客户端形态为对称 `[-r, r]`（视觉不可分辨）。

## 量化（服务器内，round-57-server.tsv）

| 基准 | 旧（N 次单发） | 新（单次批量） | 提升 |
|------|----|----|------|
| particleCloud.n5（典型调用） | 93.39 ns | 19.61 ns | **4.76x** |
| particleCloud.n10 | 166.49 ns | 12.46 ns | **13.36x** |

等价性（调用语义）：true（两形态各 100 轮调用无异常；散布位置移至
客户端生成，服务端不可比点集——以计数/形态语义等价断言）。

**边界说明**：无观察者时 spawnParticle 包成本为 0，上述为纯服务端
成本；生产环境每跟踪玩家每调用另有 N 包→1 包的网络与客户端收益，
基准不可测（如实标注）。

## 会话记录

COMPLETE=1、CH 插件错误 0、watchdog 2 次（基准批次固有）。

## 判定

族矩阵增补行：**粒子随机云批量化——实质（4.8-13.4x + 未计包收益）**。
`displayParticleEffect` 为施法/装置粒子效果的最常用入口（治疗爱心、
暴击、装置尘雾等数十处调用点随调用频率受益）。第十一轮循环开启
（0.11.0 后用户再触发），下一轮判定轮换新角度。
