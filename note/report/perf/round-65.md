# 性能优化第 65 轮：判定轮——视线/射线查询形态探针（零发现，第十二轮循环收敛）

日期：2026-08-17
性质：判定轮（第十二轮收敛计数 2/2）。探针角度与 r42-64 互异：
**视线/射线查询形态、眼部位置/速度读取形态**。

## 探针结果（全库扫描 + 逐点复核，零可行动发现）

1. **法术自备射线**：`getTargetBlockExact(range)` 共 5 处即时法术
   （Break/CallLightning/PlutosDecent/PhilosophersStone/MagicPaintbrush）
   ——复用 `CastInformation` 冻结射线（r2 已将施法时射线合一）需引入
   距离判定（法术 range < 命中距离时两形态语义不同：自备射线返回
   null 跳过效果，冻结 50 射线命中更远方块），而单次射线实测仅
   ~60-120ns（r2 数据：miss 单射线 63ns）——**收益噪声级且带语义
   风险，判定拒绝**（与 r2 当年"施法时射线合一、法术自备射线保留"
   的划分一致）；
2. **`getEyeLocation()`/`getVelocity()`**：全部为每次施法/使用的
   单次调用且结果逃逸进 API（setVelocity/particle 起点）——必需
   语义，无循环内重复。
