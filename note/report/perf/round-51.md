# 性能优化第 51 轮：判定轮——嵌套复杂度/重复查找/防御性复制探针（零发现）

日期：2026-08-17
性质：判定轮（收敛计数 1/2）。探针角度与 r48/r49/r50 互异：
**嵌套循环 O(n²) 复杂度、同方法重复 map 查找、API 边界防御性复制**。

## 探针结果（全库 grep + 逐点复核，全部零命中）

1. **嵌套实体/集合双重循环**：`magic/`、`listeners/` 的全部实体迭代
   均为单层（getNearbyEntities / getTargets 结果的一次遍历）；
   AbstractVoid/Bobulate 的两段循环为顺序关系（不同集合、不同方法段），
   非嵌套——无 O(n²) 形态（r18/r49 族已清零 `List<Block>` contains，
   本角度确认无其他嵌套嫌疑）；
2. **重复 map 查找**：`getProjectileMap().get(...)` 等调用点均为单次
   查找后使用；`MobCandleListener` 空表早退（r13）后单遍 keySet
   迭代——无同键二次查找形态；
3. **防御性复制**：`new ArrayList<>(...)`/`new HashMap<>(...)` 命中
   全部为字段初始化（新容器构造），方法体内无集合复制点。

## 判定
