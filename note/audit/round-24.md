# 审计第 24 轮：组合/复杂操作序列安全

日期：2026-08-15
范围：多步操作链、跨玩家/跨机械/跨生命周期组合、对抗性序列推演

## 基线认知（推演前提）

1. **Bukkit 主线程模型 + 本附属全部 ticker `synchronous()=true`** → 所有交互/tick/事件串行执行，**不存在真并发竞态**；组合风险只剩"同 tick 顺序"与"跨 tick 状态残留"两类。
2. **物品实体唯一性**：掉落物/手持/槽内物品是同一实体或明确转移——"同一物品同时在两机处理"类攻击在几何与实体模型上不可构造。

## 组合链推演结论

| 组合场景 | 结论 |
|---------|------|
| **镀金经济全链**（镀金器扣棱镜 → 祭坛产镀金芽 → chunk PDC 往返 → 手动破碎 ×2~×4 掉落 + 印记） | 闭环：gilded 标记 PDC→state→PDC 往返一致（round-4 防御）；破碎 `gilded && manual` 防活塞绕过（round-2）；shards 值域 0-3，×4=12 < 64 无超堆叠 |
| **跨玩家 GUI × 破坏**（A 开面板/配置器放物品，B 破坏机械） | onBreak 无条件 dropItems 全部槽位（round-2/6 修复后）；A 的光标物品由 Bukkit 关闭返还——无吞物品 |
| **双玩家同 GUI**（同配置器，A 放板 B 点按钮） | 单线程串行 + 全槽 handler；物品经 dropItems 返还地面——混乱但不丢失 |
| **快速连点**（ADD/REMOVE 连点、同 tick 多事件） | 状态条件（platesEmpty/staveIsEmpty/map 判空）使重复操作幂等或无操作 |
| **施法 × 物品流转**（施法后取板/丢法杖/换槽） | ticker 独立于物品持有；充能先结算（round-2）——无回滚需求 |
| **召唤物 × 主人下线/换维度/骑乘转移** | round-12/13 三层防护（离线清理+AI 同世界+断路器）闭环 |
| **镀金 2 秒展示窗口 × 下线/关服** | DisplayItem 落点固定；onDisable 的 clearAll 经 kill→consumer 掉落，先于世界保存——物品不丢 |
| **四机邻置物品争夺**（镀金器 3 格牵引 × 面板/池 0.3 吸收 × 虚空 1.25） | 拉锯/偏移属玩法层面，实体唯一保证不重复计入 |
| **spells.yml 运行时禁用 × 施法中** | 每次施法检查（SPELL_DISABLED）；进行中 ticker 跑完即止 |
| **现实祭坛 saveMap 迭代 × 同 tick 破碎**（跨玩家） | 监听器与 ticker 串行，迭代中无修改路径 |

## 数值发现（记录不改，上游设计）

`dropShards` 的镀金印记掉落在 **9 个类型条目循环内独立尝试**（每条目 rarityId%）——镀金神话芽"至少一个印记"概率 ≈ 37%（名义 5% 的 ~9 连击）。属上游一贯数值设计，非缺陷；如需收紧可移出循环。

## 结论

组合/复杂操作维度无新缺陷——前 23 轮的各环节防御在组合序列下相互衔接成立（串行模型 + 实体唯一 + 状态条件幂等）。
