# 真人客户端 GUI 交互层复核清单

> 由审计第 56 轮整理。本清单归集自动化 harness（mineflayer）无法覆盖或
> 不可靠覆盖的 GUI 交互层验证项，供真人客户端一次性复核。
> 每项均注明：来源轮次、自动化已覆盖的部分、真人需确认的动作与预期。

## 清单

### 1. 三个图鉴的翻页与返回（来源 r46）

- **已自动化**：三 FlexGroup 生产路径打开（零异常）、翻页数据层
  （perf r21-23/31 等价性断言）、`/ch rank` 统计读取。
- **真人动作**：`/ch spells`、`/ch stories` 与镀金集打开 → 连续点击
  "下一页/上一页" 至末页再返回 → 点入详情再返回。
- **预期**：翻页流畅、图标与解锁状态正确、无掉线/卡界面、返回上级
  正确；快速连点无异常（r24 已推演幂等，供实测对照）。

### 2. 法杖配置器按钮链（来源 r48）

- **已自动化**：放置注册、槽位填充（法杖 19/充能板 14）、ADD/REMOVE
  处理器逐行复核（损坏板双退还路径）、组装 PDC 断言工具就绪
  （`chdriver configurator ... assert`）。
- **真人动作**：放入法杖与充能板 → 点击"保存法杖"（槽 30）→ 检查
  法杖 PDC 绑定；再点击"移除法术板"（槽 12）→ 板逐槽返还。
- **预期**：组装后法杖可施放绑定法术；移除后四槽板全部返还且法杖清空。

### 3. 魔法传送网传送（来源 r49）

- **已自动化**：绑定生产路径（真实 PlayerInteractEvent → PDC 写入，
  两度实证）、传送链代码复核（零异常零缺陷）。
- **真人动作**：Shift+右击路标绑定 → 远离 → 右击传送。
- **预期**：传送落点为路标上方偏移 (1,1,1)；路标被破坏后提示
  "路标不可用"；无权限领地内提示"路标不可用"。

### 4. 机械 GUI 物品取放手感（来源 r36/r38 附注）

- **已自动化**：五大机械的物品进出（T5 自动吸取/推出、驱动填充、
  onBreak 无条件掉落）。
- **真人动作**：向记录者面板/祭坛/液化池/镀金器/配置器各放取物品；
  shift 点击放入与取出。
- **预期**：`BlockMenuPreset.clone` 放行背包侧点击（r36 溯源），
  取放应如常工作；关界面时机械内物品不丢。
